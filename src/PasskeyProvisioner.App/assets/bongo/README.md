# Bongo cat images

`bongo-l-*.png`, `bongo-r-*.png` and `bongo-base.png` come from
https://github.com/Wreckstation/bongo-cat-for-streamers (GPL-3.0, see `LICENSE-GPL-3.0.txt`), which is based on the
Bongo Cat meme. Credits from that project: the original creator of Bongo Cat is
[StrayRogue](https://twitter.com/StrayRogue); the transparent artwork is by
[mandash1996](https://www.deviantart.com/mandash1996/art/Bongo-Cat-Meme-764472620). Change: in `bongo-base.png` the opaque white area below the desk line was made transparent so the cat sits
on the theme background. Keep the license file with the images when you redistribute them.
